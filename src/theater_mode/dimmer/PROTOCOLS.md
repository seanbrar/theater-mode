# Vendored Wayland Protocol Bindings

The `*-protocol.c` and `*-client-protocol.h` files are generated by `wayland-scanner` from upstream Wayland protocol XML definitions and vendored here to keep the build lightweight without requiring `wayland-protocols` packages at install time.

## Sources

| Protocol | Upstream Repository | Path |
| --- | --- | --- |
| `viewporter` | [wayland-protocols](https://gitlab.freedesktop.org/wayland/wayland-protocols) | `stable/viewporter/viewporter.xml` |
| `xdg-shell` | [wayland-protocols](https://gitlab.freedesktop.org/wayland/wayland-protocols) | `stable/xdg-shell/xdg-shell.xml` |
| `single-pixel-buffer-v1` | [wayland-protocols](https://gitlab.freedesktop.org/wayland/wayland-protocols) | `staging/single-pixel-buffer/single-pixel-buffer-v1.xml` |
| `alpha-modifier-v1` | [wayland-protocols](https://gitlab.freedesktop.org/wayland/wayland-protocols) | `staging/alpha-modifier/alpha-modifier-v1.xml` |
| `wlr-layer-shell-unstable-v1` | [wlr-protocols](https://gitlab.freedesktop.org/wlroots/wlr-protocols) | `unstable/wlr-layer-shell-unstable-v1.xml` |

## Regenerating

To update or regenerate protocol bindings from upstream XML:

```sh
set -e
scratch=$(mktemp -d)
trap 'rm -rf "$scratch"' EXIT

wp=https://gitlab.freedesktop.org/wayland/wayland-protocols/-/raw/main
wlr=https://gitlab.freedesktop.org/wlroots/wlr-protocols/-/raw/master

curl -sS -o "$scratch/viewporter.xml"                  "$wp/stable/viewporter/viewporter.xml"
curl -sS -o "$scratch/xdg-shell.xml"                   "$wp/stable/xdg-shell/xdg-shell.xml"
curl -sS -o "$scratch/single-pixel-buffer-v1.xml"      "$wp/staging/single-pixel-buffer/single-pixel-buffer-v1.xml"
curl -sS -o "$scratch/alpha-modifier-v1.xml"           "$wp/staging/alpha-modifier/alpha-modifier-v1.xml"
curl -sS -o "$scratch/wlr-layer-shell-unstable-v1.xml" "$wlr/unstable/wlr-layer-shell-unstable-v1.xml"

for p in viewporter single-pixel-buffer-v1 alpha-modifier-v1 wlr-layer-shell-unstable-v1; do
    wayland-scanner client-header "$scratch/$p.xml" "$p-client-protocol.h"
    wayland-scanner private-code  "$scratch/$p.xml" "$p-protocol.c"
done
wayland-scanner private-code "$scratch/xdg-shell.xml" xdg-shell-protocol.c
```
